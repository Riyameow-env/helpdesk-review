## Окружение
Python 3.10 или новее. Внешние библиотеки не требуются. Команды выполняются из корня проекта. Если в вашей системе команда называется python3 или py, замените python на неё.

## Запуск
```sh
python --version
python demo.py
python -m unittest discover -s tests -v
python tools/static_review.py helpdesk.py
```
Исходный smoke-тест проверяет только обычное создание. Его успех не означает выполнение всех требований.

## Порядок работы
День 1 — требования, карта проекта, чек-лист, issue.
День 2 — анализатор, тест-кейсы, автотесты, отчёт.
День 3 — исправления в ветке, Pull Request и взаимное ревью.
День 4 — повторная проверка, слияние и итоговое заключение.
